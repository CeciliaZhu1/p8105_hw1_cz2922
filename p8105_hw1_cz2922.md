The mean can be calculated for the numeric and logical variables, but
not for the character or factor variables. For the logical variable, R
treats `TRUE` as 1 and `FALSE` as 0, so the mean represents the
proportion of values that are `TRUE`. The character and factor variables
return `NA` because they are not numeric or logical.

``` r
as.numeric(pull(problem2_df, positive))
as.numeric(pull(problem2_df, character_vector))
as.numeric(pull(problem2_df, factor_vector))
```

Converting the logical variable to numeric changes `FALSE` to 0 and
`TRUE` to 1, which explains why its mean can be calculated. Converting
the character variable to numeric produces `NA` values because the
letters cannot be interpreted as numbers. Converting the factor variable
to numeric returns the integer codes corresponding to its factor levels
rather than meaningful numeric values. This helps explain why the
logical variable can be averaged directly, while the character and
factor variables cannot.
